ДЕМО-МАКЕТ ЛИЧНОГО КАБИНЕТА

Файлы:
- index.html — главная страница
- result.html — страница результата (переход по кнопке «Подробнее»)
- style.css — оформление
- script.js — работа меню и кнопки демонстрационного бланка

Как опубликовать через GitHub с телефона:
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория все 4 файла из архива.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем Save.
6. Подожди публикации и открой адрес GitHub Pages.

Это личный статический макет для самостоятельной проверки и практики. Он не подключён к внешним системам.
